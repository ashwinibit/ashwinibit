# 🌊 Ganga Water Quality Data Platform

One of my independent projects is a **data pipeline and dashboard for
analysing Ganga river water quality**.

The project works with water-quality datasets and transforms raw files
into structured information that can be analysed year-by-year.

### 🔄 Pipeline

``` text
Raw Water Quality Data
          ↓
       Download
          ↓
       Validation
          ↓
      Normalization
          ↓
     Aggregation
          ↓
       CSV Data
          ↓
    Interactive Dashboard
```

### 📊 Current Project Focus

-   🌊 Ganga river water-quality analysis
-   🇮🇳 State-level analysis across:
    -   Uttarakhand
    -   Uttar Pradesh
    -   Bihar
    -   Jharkhand
    -   West Bengal
-   📅 Year-by-year historical analysis
-   🧪 Key parameters:
    -   **DO --- Dissolved Oxygen**
    -   **BOD --- Biochemical Oxygen Demand**
    -   **pH**
-   📍 Station-level and state-level aggregation
-   🧹 Data normalization and quality validation
-   📈 Interactive dashboard visualizations
-   📥 Structured exports for further analysis
-   ⚖️ Comparison of river measurements against reference/world
    standards

### 🧱 Technology

`Python` `Pandas` `Requests` `BeautifulSoup` `OpenPyXL` `CSV` `HTML`
`JavaScript` `Chart.js` `Tailwind CSS`

This project combines **ETL, data validation, automation, visualization,
and environmental data analysis** into a single workflow.
