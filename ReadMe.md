🧠 How I Approach Problems

I like solving problems by going one level deeper.

Instead of only asking:

«"What happened?"»

I try to determine:

«"Why did it happen, where did it happen, what data caused it, and how can I prove it?"»

My typical investigation approach is:

Problem
   ↓
Application / UI
   ↓
Workflow / Process
   ↓
Database
   ↓
Relationships & Constraints
   ↓
Audit / History
   ↓
Root Cause
   ↓
Automation / Fix

This approach is particularly useful for IAM, identity governance, database inconsistencies, and complex enterprise systems.
